Install this app
iPhone/iPad (Safari) doesn't support one-tap install — add it manually:
  1. Tap the Share icon (square with an arrow) in Safari's toolbar.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add — the dashboard now opens full-screen from your home screen, no browser bar.
